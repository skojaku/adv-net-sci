## このシートの役目

講義の途中で使う3部構成のシートです。

- **Part 1**(講義の数学より前、約10分):ツールを触って「滞在確率は次数に比例する」を自分の数字で見つける。

`pen-and-paper` スキルの原則は「概念に名前が付く前に手で作らせる」です。今回は先生の希望で「講義 → 手で確かめる」の順になる箇所(Part 2、3)があります。

## Part 1: 「Drunk on the karate club」(概念ID:m07.c06、m07.c07、m07.c01)

**場面**:空手クラブの34人。友だち関係は78本。ここに目隠しの歩行者(ランダムウォーカー)を1人落とす。歩行者は各ステップで、いまいる人の友だちの1人を同じ確率で選んで移る。

| 問 | 何を求めるか | 期待される答え |
|---|---|---|
| Q1 | ツールを開く**前に**、空の座標軸の枠に曲線を描く。横軸は歩数、縦軸は「滞在回数の高い人と友だちの多い人が、どれだけ一致するか」(0=まったく、1=完全に)。 | 歩数が少ないうちは低く、増えると1に近づいて平らになる。シミュレーションでは歩数10で約0.37、100で約0.76、1,000で約0.96、5,000で約0.99(開始点により±)。直線を描く学生が出る。それが議論の材料。 |
| Q2 | ツール(QR)を開き、「Run 5,000 steps」を4回押す(合計20,000歩)。滞在が**最も多い人**と**最も少ない人**を見つけ、それぞれの友だちの数と滞在確率を書く。 | 最多は33番(友だち17人、確率0.109)か0番(16人、0.103)。最少は11番(1人、0.0064)。 |
| Q3 | 2人それぞれで「友だちの数 ÷ 滞在確率」を計算する。 | どちらも約156。11番の値は5,000歩だと±30%ほどずれる(20,000歩でも約±10%)。 |
| Q4 | 2つの数字は同じか。34人、78本という数字と比べてどう関係するか、言葉で書く。 | 156 = 2 × 78。「滞在確率 = 友だちの数 ÷ (友情の本数の2倍)」。 |

- Q3 のずれは意図的です。一致しない人が必ず出ます。「ずれは歩数が足りないせい。歩数を増やすと近づく」と議論する材料になります。
- Q2 で「最多」が33番か0番かは学生によって割れます(33番が約3/4、0番が約1/4)。どちらでも結論は同じになるので、それも議論に使えます。
- 「相関」は高校生に分からない語なので、Q1 には言葉で定義を書きます(「棒の高さが友だちの数にどれだけ沿っているか」)。

## Part 2: 「Four members」(m07.c16、m07.c31)

**場面**:4人のグループ(ダイヤ形:0と1は互いに友だちでなく、2と3は全員と友だち)。次数は 2, 2, 3, 3。

**図に与えるもの**:ネットワーク図、遷移行列 $P$(4×4)、固有値と左固有ベクトルの表。固有値と固有ベクトルは**与えます**(学生は計算しない)。

| 固有値 $\lambda_k$ | 固有ベクトル $\psi_k$(左) |
|---|---|
| 1 | (0.2, 0.2, 0.3, 0.3) |
| 0 | (−1, 1, 0, 0) |
| −1/3 | (0, 0, −1, 1) |
| −2/3 | (1, 1, −1, −1) |

| 問 | 何を求めるか | 答え |
|---|---|---|
| Q5 | 歩行者が0番から出発する $x(0) = (1,0,0,0)$。1歩後の $x(1) = x(0)P$ を手で求める。 | (0, 0, 0.5, 0.5) |
| Q6 | 2歩後の $x(2)$ を求める。 | (1/3, 1/3, 1/6, 1/6) |
| Q7 | 与えられた式 $x(0) = 1\cdot\psi_1 - 0.5\,\psi_2 + 0\cdot\psi_3 + 0.3\,\psi_4$ の、0番の成分が1になることを確かめる。 | 0.2 + 0.5 + 0.3 = 1 |
| Q8 | 各 $\psi_k$ に $P$ を1回掛けると $\lambda_k\psi_k$ になる(表のとおり)。これを使って $x(1)$ を、4つの項の和として書く。Q5 と合うか確かめる。 | $\psi_1 + 0 + 0 + 0.3(-2/3)\psi_4$ = (0, 0, 0.5, 0.5) |
| Q9 | 同様に $x(2)$ を書き、Q6 と合うか確かめる。 | $\psi_1 + 0.3(4/9)\psi_4$ = (1/3, 1/3, 1/6, 1/6) |
| Q10 | 一般の $t$ 歩後の $x(t)$ を、$\lambda_k$ と $\psi_k$ を使って書く。(手順を書く問い) | $x(t) = \psi_1 - 0.5\cdot 0^t\psi_2 + 0\cdot\psi_3 + 0.3(-2/3)^t\psi_4$ |
| Q11 | $(-2/3)^t$ を $t = 2, 5, 10$ で計算する。$t = 10$ で残っている項はどれか。$t \to \infty$ で $x(t)$ は何になるか。Part 1 の答えと比べる。 | 0.44, −0.13, 0.017。残るのは $\psi_1$ だけ。$(0.2, 0.2, 0.3, 0.3) = (2,2,3,3)/10$、これは Part 1 の「次数 ÷ 2m」(2m = 10) |

- Q11 の最後が **bookend** です。Part 1 で見つけた「次数 ÷ 2m」が、固有値1の項そのものだと分かります。
- 負の固有値(−1/3、−2/3)は符号が交互に変わる項です。実際の歩行者は {0,1} と {2,3} を行き来します。これも講義では触れていないので、Q11 の議論で先生が拾ってください。
- 与えた固有ベクトルは、各自で代入して検算できるようにしてあります(Q8、Q9 が検算を兼ねる)。

## Part 3: 「Two rooms」(m07.c24、m07.c17)

**場面**:12人の部活。0〜5番が部屋1、6〜11番が部屋2。各部屋はほぼ全員が友だち(各部屋は完全グラフから1本ずつ抜いた)。部屋どうしをつなぐ友だち関係は2本だけ(2–8と5–11)。

**コード1セル**(marimo、QR+短縮リンクで開く):

```python
import numpy as np, matplotlib.pyplot as plt   # 図の道具は seaborn / altair に変更の可能性あり(下記の確認事項)
edges = [(i, j) for r in (range(0, 6), range(6, 12)) for i in r for j in r if i < j]
edges = [e for e in edges if e not in [(0, 3), (7, 10)]] + [(2, 8), (5, 11)]
A = np.zeros((12, 12)); 
for i, j in edges: A[i, j] = A[j, i] = 1
P = A / A.sum(axis=1, keepdims=True)
vals, vecs = np.linalg.eig(P)
order = np.argsort(-vals.real)
print(np.round(vals.real[order], 3))
plt.scatter(range(12), vecs[:, order[1]].real)   # 第2固有ベクトル
```

| 問 | 何を求めるか | 答え |
|---|---|---|
| Q12 | セルを実行する。点プロットで、正の値の人と負の値の人はそれぞれ誰か。 | 0〜5番が一方の符号、6〜11番が他方(符号の向きは実行ごとに逆になりうる) |
| Q13 | 正の人たちと負の人たちに共通するものは何か。 | 部屋。第2固有ベクトルは2つの部屋を符号で分ける |
| Q14 | コードが表示した固有値を見る。$t = 5$ と $t = 100$ のとき、$\lambda_2^t$ はいくつか(0.889 を使う)。ほかの固有値の $t$ 乗(たとえば $0.4^5$)と比べて、どちらの時刻でどの項が残るか。 | $0.889^5 = 0.55$、$0.889^{100} = 0.000008$。ほかの10個は5歩後には約0.01以下(最大でも絶対値0.42なので $0.42^5 = 0.013$)。5歩後は「次数の項」と「部屋の項」が残り、100歩後は「次数の項」だけ |
| Q15 | 一文で書く。歩行者が出発して数歩のあいだ、歩行者の位置から何が分かるか。長い時間が経つと何が分かるか。 | 数歩のあいだは「どの部屋から出発したか」(コミュニティ)。長い時間では「次数」だけ。スライド2枚目の問い(「短い歩きは部屋、長い歩きは次数」)への答え |

- **Part 1 の Q1** と **Q15** が bookend です。「短い歩きと長い歩きで分かることが違う」を、最初は直感、最後は固有値で説明します。

## 先生に決めてほしいこと(私の推奨つき)

1. **ツールの小改造を許すか。** Part 1 の Q2 には、2つの追加が必要です。デフォルトの動作は変えず、URL パラメータで有効にします。
   - (a) 橙色の目盛り(k/2m)を隠す。これが見えていると Q3 の答えが画面に出ています。例:`?hideLaw=1`

   推奨:(a)(b)をどちらも追加する。パラメータを付けない URL は去年のままです。「去年使ったままで」の約束も守れます。許さない場合は、シートに34人の友だちの数の一覧を印刷し、確率は棒グラフの目盛りから読む(精度は悪い)ことになります。
2. **コードを動かす場所。** 推奨:marimo ノートブックを molab に置き、`go.skojaku.com/m07p3`(のような短縮リンク)の QR をシートに載せる(Module 1、2 の方式)。必要なら、リンクを作る作業は先生の確認後に私がやります。

4. **行ベクトルか列ベクトルか。** 先生のご依頼は $x(t) = P^t x(0)$ でしたが、講義ノートは $x(t) = x(0)P^t$(行ベクトル、$P_{ij}$ は $i$ から $j$ への確率)です。M06 の添字の規則(辺の向きに添字を並べる)とも合います。推奨:講義ノートのままにして、行ベクトルで統一する。列ベクトルにする場合は、シートとスライドの式をすべて転置する必要があります。
5. **Part 2 の与え方。** 固有値と固有ベクトルは与え、学生は代入と検算だけにしています(固有値の計算は M06 で扱い済みのため)。「自分で固有値を求める問い」を増やしたい場合は、ダイヤ形が 0, −1/3, −2/3, 1 と整った値なので手計算できます。ただし時間が足りなくなります。
