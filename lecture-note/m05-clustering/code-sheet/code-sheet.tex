\textbf{How to use this sheet.} Each framed \textbf{Box} below goes into the
matching empty cell of the notebook. \textbf{Type it by hand} rather than pasting it:
writing a line is how you find out what it does. Press \textbf{Shift+Enter} to run
a cell. The notes under a box say what each numbered line does.

\textbf{Typing tips.} Spelling, capital letters, brackets and quotation marks all
matter. Colab may add a closing bracket or quote for you; when you type the closing
one yourself, it steps over the extra one. Indent with the Tab key.

everything after a break. Run the three setup cells again. Anything else: raise your hand.
