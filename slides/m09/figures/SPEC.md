# Figure spec for the m08-gnn v3 deck

You build figures for a Marp slide deck (1280 x 720 px slides, `slide-math` theme).
Read first: `figures/common.py` (do not edit it), `~/.claude/skills/slide-math/FIGURES.md` and `figkit/figkit.py`.

## Hard rules (the user's, 2026-11-08)
1. **Every word and number in a figure is at least 35 px (= 26 pt).** `common.py` raises figkit's sizes to 35 px.
   Do not use `\small`, `\footnotesize`, `\scriptsize`, `\tiny` or a smaller `\fontsize`. Math sub/superscripts are the only exception.
   If a label does not fit at 35 px, delete the label or make the object bigger. Never shrink the type.
2. **Little text.** Only the words that a student must read. No sentences. No legends if a label can sit on the object.
3. **One unit = one slide px.** A figure must not be larger than its W x H below (check: `python3 figures/check_size.py NAME W H`).
   Fill the box well: use the whole W x H, do not leave one third empty.
4. TikZ through `figkit` (`B(name, *parts)`), PNG images through `picture()` for photos/spectra. **No matplotlib. No bar charts (a value is a dot).
   No green.** Black 2 px lines, white fills; lavender `hl` (#F4E6FF) marks what the slide is about, cyan `hlc` the alternative.
   Data series colours: blue `snew` #0072B2 and vermillion `sbase` #D55E00 (also `sthree` #E69F00, `sfour` #56B4E9, `sfive` #CC79A7).
   Sequential values: white -> `snew`. Diverging values: vermillion - white - blue. Hop/step scale in lavender:
   #F4E6FF, #D9B8F5, #B88AE0, #9B6BC9. Greys for the unselected.
5. **Real numbers.** Anything computed (pixel values, spectra, GCN output, eigenvectors, softmax, degrees, edge weights) is computed
   in the script with numpy/networkx/scikit-image (fixed seeds), never typed by hand.
6. Photo: `camera()` (512 x 512 gray cameraman). Karate club: `karate_layout()` (real data).
7. Look at every figure after building: `python3 figures/preview.py NAME`, then Read `figures/_build/png/NAME.png`. Fix overlaps, clipped text,
   unreadable nodes, edges through labels. Keep fixing until it is clean. A figure is a finished slide figure, not a sketch.
8. Do not edit files other than your own `figures/fig_<group>.py` and the files it writes (`figures/<name>.svg`, `figures/img/*`).
   Do not run git. If `common.py` is missing something, put a helper in your own file and tell me in the report.
9. Run with: `cd slides/m09 && uv run --quiet --with numpy --with scipy --with networkx --with pillow --with scikit-image python figures/fig_<group>.py`

Script shape (see common.py): each figure is a function that calls `B("name", *tikz_parts)`; `if __name__ == "__main__":` calls them all.
Coordinates are px with y up (TikZ). Use `P(x, y)` for coordinates inside raw TikZ strings.
