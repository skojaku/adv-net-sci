## ストーリー(四幕)

- **第1幕 Build(物語)** — 1926年モラヴィア。第一次大戦後のチェコスロバキアが最少ケーブルで全町を電化したい。West Moravian Power Company(Západomoravské elektrárny)の友人経由で数学者 Otakar Borůvka に問題が届く。→ 重み付きネットワーク、木・全域木、MST、Kruskal/Prim、貪欲最適性、タイ、Borůvka 種明かし。
- **第2幕 Break(その物語の数学)** — 完成した最安の送電網から1ノード消すと? 木の致命的脆さ → 壊れ方を測る(接続率・プロファイル・R-index)→ ランダム故障 vs 狙い撃ち → adaptive 攻撃。1日目はここで「何%壊したら崩壊するか、次回1つの式で予言する」とクリフハンガー。
- **第3幕 一般化** — 水たまりパーコレーションの相転移 → 攻撃は逆回しのパーコレーション → 辺をたどると高次数に偏る q(k) → κ → Molloy-Reed → f_c → Poisson (f_c = 1−1/⟨k⟩) vs scale-free (f_c→1)。
- **第4幕 Build it back(逆説とエッジケース、全て問いで)** — scale-free は無敵か? → ハブ狙い撃ちで即崩壊(robust-yet-fragile)→ 効率 vs 安全 → 設計原理 → モラヴィアの現代送電網は MST+冗長ループ → エッジケース4題 → 復習 → M4 予告。

### Part 3: Break it(第2幕、約14枚)
1. 完成した MST 網。問い: **どの町を壊すと一番痛い?**(m01「どの橋を落とす?」の型)
2. 中心近くの1ノードで分断 → 木には迂回路がない(**c09**)

4. 壊れ方を測る: 接続率 = 最大成分 / 元のサイズ(**c11**)
5. 逐次破壊で曲線を描く: robustness profile(**c12**、モラヴィア木上でステップビルド)
6. 曲線を1数に: R-index = 面積(**c13**、手計算例)
7. 壊す順で曲線が変わる: ランダム故障(**c14**)vs 狙い撃ち(**c15**)
8. 問い: 順位は最初に決める?毎回測り直す?→ adaptive 攻撃の方が破壊的(**c16**)
9. **ライブデモ: network-robustness.html**(マイルストーン)
10. クリフハンガー: 何%で崩壊? 次回、1つの式が予言する
11. (授業運営)ペーパー演習 Build it, Break it, Build it back を一括実施

### Part 4: Percolation(第3幕前半、約7枚、2日目開始)
1. 扉 → 水たまりグリッドの問い: 各マスが確率 p で水たまり。いつ巨大水たまりが出現?(**c17**)

3. **ライブデモ: marimo スライダー**(マイルストーン)
4. 埋めた順は無関係、割合だけが効く(**c30**)
5. 攻撃は逆回しのパーコレーション(**c18**)— 同じ数学、逆向き

### Part 5: The formula(第3幕後半、約12枚)
1. 問い: 崩壊を予言する数は?
2. 辺をたどって着く相手は平均的なノードではない: q(k) = k p(k)/⟨k⟩(**c19**、袋から手を掴む図)
3. 着いた先の平均次数 = κ = ⟨k²⟩/⟨k⟩(**c20**)
4. 分岐因子 κ−1: 入ってきた辺を引く。1 を超えれば探索は growing
5. Molloy-Reed: κ > 2 で巨大成分(**c21**)
6. **Your turn: κ を計算**(スター vs パスなどの小グラフ、マイルストーン)
7. ランダム故障: 生き残り率 (1−f) を掛けて (1−f)(κ−1) = 1 → f_c = 1 − 1/(κ−1)(**c22**)。厳密版は付録参照の一言
8. Poisson 網: ⟨k²⟩ = ⟨k⟩²+⟨k⟩ → κ = ⟨k⟩+1 → f_c = 1 − 1/⟨k⟩(**c23**、⟨k⟩=4 なら 75% などの実数値)
9. scale-free 網: ⟨k²⟩ → ∞ → f_c → 1、ほぼ全滅させないと壊れない(**c24**)
10. (c25 の有限サイズ補正はスライド外。ノート参照)

### Part 6: Robust yet fragile(第4幕前半、約10枚)
1. 問い: では scale-free 網は無敵?(question)
2. シミュレーション曲線: ER vs scale-free × ランダム vs 狙い撃ち(2×2 を1枚ずつビルド)→ ハブ狙い撃ちで即崩壊(**c27**、式 c26 は使わずデータで見せる)
3. 同じハブが強さの源泉であり急所 — robust-yet-fragile
4. 効率 vs 安全のトレードオフ: 万能構造は無い(**c31**)
5. 問い: **あなたが設計者なら?** モラヴィア網に2本足すならどこ?(discussion、マイルストーン)
6. 設計原理(**c28**): 次数の均し、冗長経路、ハブ防護、階層化、適応(討論の回収として提示)
7. Build it back: 現代のチェコ送電網 = MST + 冗長ループ。1926年の答えと2000年の答えを一枚に(円環の締め)

### Part 7: Edge cases(第4幕後半、約9枚、全て問い→答えの対)
1. 全員次数2のリング: κ は?(question)→ κ=2 ちょうど閾値、辺1本でパスに墜落する限界構造
2. Poisson で ⟨k⟩=1 にすると?(question)→ κ=2、m02 の巨大成分出現 ⟨k⟩=1 が公式から再発見される
3. 次数でなく媒介中心性で狙ったら?(question)→ もっと壊れる、ただし計算コスト大。M6 への伏線
4. 三角形だらけの実網(M2)でも予言は当たる?(question)→ 木状近似の破綻。証明の前提を突く
