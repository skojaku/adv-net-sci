## この単元の最大の危険

**「中心性カタログ講義」への退化。** 9個の指標を順に並べると物語が死ぬ。対策は二つ:

1. **一つの網、王が入れ替わる。** 全指標を同じローマ街道グラフの上で計算し、同一ジオメトリの
   同じ地図を毎回出す。変わるのはノードの濃淡(スコア)と王冠の位置(1位)だけ。指標の定義では
   なく**指標間の不一致**が主役になる。
2. **同じ発見が6回繰り返された。** Landau 1895 → Brin & Page 1998 の系譜を PageRank の直前に
   置き、それまでに教えた固有ベクトル・Katz・HITS が全て同一方程式の変形だったと明かす。

## ストーリー(四幕)

- **第1幕 The Golden Milestone(物語)** — 紀元前20年、フォロ・ロマーノ。アウグストゥスが
  Milliarium Aureum を建て、帝国中の距離がこの一点から測られるようになる。重要さが**勅令で
  決められた**時代。街道地図 → 12都市グラフへの抽象化。そして学生自身のクラブ網で、直感が
  すでに二つの異なる「重要」に割れることを体験させる (**c01**)。
- **第2幕 その物語の数学** — ローマ街道グラフの上で、次数 → 近接 → (切断で壊れる) → 調和 →
  離心 → 媒介 を計算する。毎回同じ地図、動くのは王冠だけ。1日目はブローカー(次数2なのに
  媒介1位)で終わり、「では、重要な友を持つ人は重要か?」のクリフハンガーを置く。
- **第3幕 一般化** — アイソポス「人は付き合う友で分かる」。再帰 → 固有ベクトル中心性 →
  Perron–Frobenius → べき乗法(ここまで無向のローマ網の上)→ 局在化の失敗 → Katz。
  街道は両向きだがリンクは片向き、という一点で Web へ移り、HITS → **系譜の種明かし** →
  PageRank(1998年スタンフォード)→ テレポーテーション → Personalized PageRank。
- **第4幕 選択とエッジケース(全て問いで)** — ローマ網に帰り、王冠一覧で円環を閉じる。
  目的別の選び方、計算コスト、星グラフ(全面一致)vs パスグラフ(全面決裂)、応用3題。
  最後に「PageRank は実はランダムウォークだった」で M07 へ。

## 作業用グラフ(DECK_SPEC で数値確定・検証)

### 無向・12都市のローマ街道グラフ
- 候補都市: Roma, Mediolanum, Lugdunum, Massilia, Tarraco, Carthago, Byzantium,
  Thessalonica, Athenae, Colonia Agrippina, Londinium, Alexandria
- 制約:
  - 辺は実在のローマ街道・主要航路に対応させる(捏造しない)
  - planar 配置で辺交差ゼロ(F2)、約18辺
  - 全ノードが手計算可能な距離にある(直径 4〜5 程度)
  - **degree / closeness / betweenness / eccentricity / eigenvector / Katz の1位が
    最低でも3種類の異なる都市になること** — これがデッキの背骨。ならなければ、実在の街道の
    範囲内で都市・辺の取捨を調整する
  - 切断の実演用に、1辺だけ落とすと孤立する変種を用意(c05/c06 用)
- **史実には賭けない**: 「ローマが1位でない指標がある」ことは示すが、それが歴史的事実と
  一致するとは主張しない

### 有向・8ページの Web 網
- 8ノード・約14リンク。仕込むもの:
  - 出リンクを多数持つ「リンク集」ページ(ハブ王候補)
  - 多数から指される「原典」ページ(オーソリティ王候補)
  - 出リンク0の行き止まりページ(テレポーテーションの動機)
  - 相互リンクの小さな塊(PageRank が HITS と食い違う源)
- **HITS のハブ王と PageRank の王が異なること**を数値で確認する

### 検証必須(スペック段階で全て計算・出典確認)
- 12都市グラフの全指標の値と各指標の1位、王冠が実際に動くこと
- 星グラフで closeness の最大値がちょうど1になること(c28)
- σ を数える例(同点の最短経路が2本ある小グラフ)
- 8ページ網の HITS(ハブ/オーソリティ)と PageRank の値、王が食い違うこと
- λ_max(A) の値、安全な λ(例 0.9/λ_max)、および λ > 1/λ_max で実際に負のスコアが出ること
- 局在化の図の実数値(密な塊 + 周辺で、周辺のスコアがどこまで潰れるか)
- 計算量の数値(degree O(M) / closeness・betweenness O(NM) / べき乗法 反復あたり O(M))
- 史実: Milliarium Aureum(アウグストゥス、紀元前20年、フォロ・ロマーノ)、アイソポス(紀元前
  6世紀頃)、Perron 1907 / Frobenius 1912、Bavelas 1950(closeness)、Beauchamp 1965
  (harmonic)、Freeman 1977(betweenness)、Brandes 2001、Landau 1895、Seeley 1949、
  Katz 1953、Hubbell 1965、Bonacich 1972、Kleinberg(HITS)、Brin & Page 1998
