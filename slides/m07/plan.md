## 数学の説明の順番と、使う絵

直感を先に出し、数学で裏付けます。数学は式を出しますが、それぞれに目で見える絵を付けます(M06と同じ記法:丸=固有値、縦長の棒=固有ベクトル、横長の棒=その転置、正方形=行列)。

| 話題 | スライド | 絵 |
|---|---|---|
| 遷移行列 $P$ | 16 | 12頂点「2つの部屋」ネットワークと $P$ の熱地図(2つの濃いブロック) |
| 1歩 = 行ベクトル × 行列 | 17 | 横長の棒 × 正方形 = 横長の棒 |
| $P^t$ | 18〜20(ビルド) | $t = 1, 5, 40$ の熱地図。ブロックがにじみ、最後は全行が同じ(= $\pi$) |
| 固有値の復習(軽く) | 21〜22 | M06の `decomp-sum.png` をそのまま再利用 → $P$ でも同じ形(丸と棒の和) |
| べき乗は丸だけに効く | 23〜25(ビルド) | $t$ が増えると丸が縮む。1番目の丸だけ残る |
| どの丸が最後まで残るか | 26〜27 | 12個の丸。答えは2番目 |
| ミキシングタイム | 28〜31 | 初期分布が $\pi$ に近づく棒グラフ → 距離の曲線 → $\varepsilon$ の線 → 交点が $t_{\mathrm{mix}}$ |
| 問い:完全グラフ vs 橋1本 | 32〜35 | 1歩 vs 約14歩(15倍) |
| スペクトルギャップ | 36 | $\lambda_2$ の目盛り(完全グラフ、空手クラブ、2つの部屋、橋1本、1,000個のリング) |
| 固有値1は必ずある | 39 | $P \cdot \mathbf{1} = \mathbf{1}$(各行の和が1) |
| 1より大きい固有値はない | 40 | 平均を取っても最大値は超えない |
| 固有値1の項 = 定常分布 | 41 | 縦の1の棒 × 横の $\pi$ の棒。ツールの橙色の目盛りとつなぐ |

固有値1の話は、先生のご希望どおり「事実として」教え、理由は絵1枚ずつ(各行の和が1、平均は最大を超えない)に留めています。証明はしません。

## 確認済みの数字(numpy で計算)

- 空手クラブ(34人、78本):$\lambda_2 = 0.868$、緩和時間 $\tau = 7.6$ 歩。最悪の出発点で 1-ノルム距離が 0.5 以下になるのは約10歩。
- 滞在確率と次数の相関(平均):10歩 0.37、30歩 0.53、100歩 0.76、300歩 0.89、1,000歩 0.96、5,000歩 0.99、20,000歩 1.00。
- 最多滞在の人:5,000歩で33番が約74%、0番が約26%。どちらでも 次数÷確率 は約156(= 2m)。
- 2つの5頂点クリーク+橋1本(21本):$\lambda_2 = 0.927$、$\tau = 13.7$。10頂点の完全グラフは $\lambda_2 = -1/9$、$\tau = 0.9$。15倍の差。
- 12頂点「2つの部屋」(30本、0〜5と6〜11、0–3と7–10を抜き、2–8と5–11で結ぶ):固有値 1, 0.889, 0, 0, 0, −0.088, −0.2, −0.2, −0.266, −0.333, −0.379, −0.423。$\tau = 9.0$。第2固有ベクトルは符号で部屋を完全に分ける(±1 と橋の端点だけ ±0.74)。
- 歩行者が0番から出発:部屋1にいる確率は $t = 0, 1, 2, 3, 5, 10, 20, 40$ で 1, 1, 0.92, 0.88, 0.80, 0.67, 0.55, 0.505。
- 4頂点ダイヤ(次数 2, 2, 3, 3):固有値 1, 0, −1/3, −2/3。$x(2) = (1/3, 1/3, 1/6, 1/6)$。
- 2つの部屋の滞在時間は約21歩(橋を使う確率が1歩あたり1/42、部屋1にいる確率が1/2より)。

最終版の図を描くときは、これらを `smallgraphs.py` に置き、`check()` で表明します(M06の流儀)。

## 先生に決めてほしいこと(私の推奨つき)

1. **ツールの小改造**。ペン＆ペーパー計画の確認事項1を参照。推奨:両方追加(パラメータなしは去年のまま)。
2. **左右の固有ベクトル(スライド22)**。$P$ は対称でないので、固有ベクトルは左(横長の棒)と右(縦長の棒)の2種類あり、互いに次数で重みを付け直したものです。M06の $A$ は対称で、棒は1種類でした。
   推奨:図では縦長と横長を別の棒で描き、「同じベクトルの次数による重み付け違い」と1行の脇書きだけ付ける。詳細は付録に回す。代案:対称化した行列($D^{-1/2}AD^{-1/2}$)を使えばM06とまったく同じ図になるが、「$P$ の固有値は同じ」という説明が1枚増える。
3. **距離の測り方**。講義ノートは 1-ノルム($\|x(t) - \pi\|_1 \le \epsilon$)です。スライドのモックでも1-ノルムにしています。全変動距離(その半分)のほうが、値が0〜1に収まり読みやすい(計算値はこちらで確認済み)。推奨:ノートに合わせて1-ノルム、横軸の端は2。
4. **行ベクトルか列ベクトルか**。ご依頼は $x(t) = P^t x(0)$ でしたが、ノートは $x(t) = x(0)P^t$(行ベクトル)です。M06の添字の規則(辺の向きに並べる)とも合います。推奨:ノートのまま行ベクトルで統一。
5. **この回の範囲**。M07 は2回あります。この資料は数学の山場(固有値、ミキシングタイム、第2固有ベクトル)に絞りました。到達時間・コミュニティの見つけ方(Walktrap、Infomap)・PageRankは入っていません。次回に回してよいですか。入れる場合は時間が足りません。
6. **ペン＆ペーパーの時間**。Part 1 に10分、Part 2〜3 に20分、合わせて30分を取っています。短くしたい場合は Part 3 の Q14 を板書に回せます。
7. **最後のスライド**。講義用のため「Thank you」ではなく、冒頭の空手クラブの絵に戻り、次回の問い(到達時間)を置いています。
