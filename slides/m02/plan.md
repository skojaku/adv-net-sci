## 各パートの要点

### Part 1 — 物語(第1幕)
- 導入の問い: 「オマハの農夫とボストンの株屋。知人づてに手紙を届けると何人経由する?」予想を挙手で。
- 実験の仕組みを1枚1手順で開示(パケット→ファーストネームで知る人へ転送→到達まで)。
- 結果の驚き: 160通中64通、**中央値約6人**。"Six degrees of separation" はミルグラム自身の言葉ではなく Guare の戯曲(1991)。
- 再現: Yahoo email(24,000人超スタート、完走384、完走平均約4、減衰補正で5〜7)/ Facebook 2012(7.21億人・690億友情、平均4.74)。
- Wikiraceライブ → 教訓: 経路が**ある**ことと、局所知識だけで**見つけられる**ことは別(c04)。ミルグラムが示したのは後者で、より強い主張。

### Part 2 — 「6」を測る数学(第2幕)
- ミルグラム知人網: 7ノード(職業ラベル: farmer, grain buyer, teacher, minister, printer, broker's clerk, **stockbroker** など)を鎖状に6本 → これがチェーン。距離=辺の本数。
- 鎖のままの平均経路長 = 56/21 = **8/3 ≈ 2.67**、直径6(P7 の全21ペア、Σ d·(7−d) = 56。検算済み)。
- 近道(shortcut候補)を2本追加するビルド → 同じ図で距離が縮むのを見せ、d(i,j)・最短経路・平均経路長・直径を正式定義。近道追加後の全ペア距離は DECK_SPEC で igraph により厳密計算し、図生成スクリプトに assert を置く。
- ワークシートA: 同じ図で指定ペアの距離+平均経路長を紙で計算 → スライドで段階開示の答え合わせ。

### Part 3 — もう半分: クラスタ(第3幕a)
- 「あなたの友人2人は互いに知り合い?」→ 三角形/開・閉トリプレットの定義(c08)。
- C_i = (iを含む三角形数) / (k_i(k_i−1)/2 … 可能ペア数)。レクチャーノートの6ノード例(A の C = 2/10 = 0.2)を流用可。
- 問い: 「(A²)_ij は長さ2のウォーク数だった。では (A³)_ii は?」→ 答え: 自分に戻る長さ3のウォーク = 三角形×2(左回り/右回り)→ C_i = (A³)_ii / (k_i(k_i−1))。
- C̄ = 平均局所クラスタ(c10)。
- 風車グラフ(ハブ+5枚羽=11ノード): 羽ノードは C_i=1 が10個、ハブは C=5/45=1/9 → **C̄ = (10+1/9)/11 ≈ 0.92**。三角形5個 → 分子15、トリプレット = C(10,2)+10 = 55 → **C = 15/55 = 3/11 ≈ 0.27**(検算済み)。問い:「同じクラスタなのになぜ割れる?」→ 答え: C はトリプレットを重みにするのでハブが支配、C̄ は全ノード等重み(c11)。
- ワークシートB: ミルグラム知人網(近道込み)で各自1ノードの C_i を計算。

### Part 4 — ものさし(第3幕b)
- **パラドックスの正面提示**(このデッキの山場): 三角形だらけ=配線は局所的 → 局所配線だけなら遠くへは何段も必要なはず → なのに実測は4〜6。両立は非自明(c17の前半をここで先出し)。
- 素朴な s_naive = C̄/L̄ → 問い「完全グラフでは?」→ C̄=1, L̄=1 で最大値。自明な網が満点になる指標は使えない(c12)。
- 規格化の相手: ER G(n,p)(c13)。「n ノードの各ペアを確率 p のコイン投げで接続」。
- 問い→答え: E[C_i] = p = ⟨k⟩/(n−1)(隣人 k 人のペアはそれぞれ独立なコイン、c23)。
- 扇形分岐図: 1 → ⟨k⟩ → ⟨k⟩² → … → ⟨k⟩^L ≈ n → L_rand ≈ ln n / ln⟨k⟩(c14)。具体例: n=8×10⁹, ⟨k⟩=150 → **L ≈ 4.6**(6次の隔たりの理論的裏付け。数値は spec で検算)。標語: **短経路はランダムでもタダで手に入る。高クラスタはタダでは手に入らない**。
- σ = (C/C_rand)/(L/L_rand)(c15)。σ>1 スモールワールド、≈1 ランダム並、<1 反スモールワールド。
- **WS1998スコアボード**(俳優・送電網・C. elegans): 各網の C/C_rand と L/L_rand を**対数軸ドットプロット**で(棒グラフは使わない方針のため)。論文 Table 1 の値: 俳優 L=3.65/L_rand=2.99, C=0.79/C_rand=0.00027(C比 ≈ 2900倍)、送電網 L=18.7/12.4, C=0.080/0.005(16倍)、C. elegans L=2.65/2.25, C=0.28/0.05(5.6倍)。**この数値は spec 段階で原論文と照合し直すこと**(記憶由来のため要検証)。
- σミニ演習: スコアボードの2つの比から σ を各自計算 →「3つとも σ≫1」で判定。

### Part 5 — 機構(第3幕c)
- 問い: 「高Cと短Lを両立する網を、自分で**作れる**か?」(Feynman の "What I cannot create…" を添える)。
- リング格子(n=20, k=4 で描画): C は高い(この例の C̄ は igraph で厳密計算し assert)、L は n に比例して伸びる(c16)。
- 対極: ランダム — 短いが三角形なし。トレードオフの1枚(c17、格子とランダムを左右対置)。
- WS再配線(c18): 確率 p で辺の片端をランダムに繋ぎ替え。**GIFビルド**(1本ずつ繋ぎ替わるアニメ、make_animations.py)。
- pスイープ曲線(c19): C(p)/C(0) と L(p)/L(0)、横軸 log p。図は引用ではなく make_figures.py 内で igraph により実測生成(再現性+assert可能)。
- 読み取り: L は p が小さいうちに急落、C は粘る → **広い中間帯**が存在。数本のショートカットが距離を崩壊させ、三角形はほぼ無傷(c20)。
- marimoウィジェット(既存 watts_strogatz_wasm.py)をブラウザでライブ操作。スライドには静止画+リンク1行。

### Part 6 — エッジケース(第4幕、すべて問い→答えの2枚組)
1. **非連結ペアがあると平均経路長は?** → d=∞(c05)で平均が発散 → 実務は最大連結成分に限る(または調和平均)。
2. **次数1(や0)のノードの C_i は?** → 分母 k(k−1)/2 = 0 で 0/0 → 慣例は C_i=0 扱いまたは平均から除外。
3. **σ < 1 の網は実在する?** → する — ただし**リング格子ではない**(検算の結果、リング格子は C/C_rand の優位が L の不利を上回り σ≈3〜5 で σ>1。n=1000, k=4 で σ≈4.96)。正解は**三角形ゼロの格子**: 2Dグリッド(道路網、20×20 で C=0 → σ=0)や k=2 の単純サイクル。「σ<1 には C をランダム未満に落とす必要がある=三角形を殺す」が教訓。Part 5 の格子図と対比して回収。
4. **ランダムグラフの作り方は2通り — G(n,m) と G(n,p) は同じ?** → ほぼ同じだが独立性が違う。辺が独立な G(n,p) だから E[C_i]=p の計算が通った(c22。Part 4 の導出を回収)。

### Wrap-up
- 普遍性: ニューロン・インターネット・道路/航空網・引用網も同じ署名(c21、extension なので1枚に圧縮)。
- 1枚地図: 格子 —(p)— WS —— ランダム、上に C と L の帯。
- m03予告: 「世界を狭くしているのは少数のショートカット。**では、それが切れたら?**」→ ロバスト性へ。

6. 毎ラウンド、教訓をメッセージに入れてコミット。
